# On-device Gemma Brain Implementation Plan (plan e)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On the merchant's phone, Gemma 4 rewords Munshi's lines, answers free questions from the shop's facts (suggesting reminders the merchant then confirms) and reads shelf photos, at ₹0 per request. Without the model, every path falls back to today's templates.

**Architecture:**
- **Pure-Kotlin core, unit-tested with fakes:**
  - `Brain` interface
  - `LlmBrain`: prompts plus guards over a one-method `Llm`
- **Android/native shell:** `ModelHost` picks E4B or E2B by RAM, downloads the pinned `.litertlm` file (or finds it pushed by adb), loads it with LiteRT-LM (GPU, then CPU) and exposes it as an `Llm`.
- **The Conductor uses the brain for three things:**
  - warmer wording of questions, prepared in the background from `/api/facts`
  - free speech → `brain.answer` → `/api/propose`
  - shelf photo → `brain.readShelf` → `/api/shelf/readings`
- The server only ever receives decisions and readings.
- **Change from spec §7:** its `reword(line, spoken)` becomes `prewarm(lines)` + `cached(line)`. The
  Conductor never waits for the model before asking: a line is spoken in the warmer wording if it is
  ready, otherwise as the template.

**Tech Stack:** Kotlin 2.3.0, Jetpack Compose, LiteRT-LM 0.16.1 (`com.google.ai.edge.litertlm:litertlm-android`), Gemma 4 E4B/E2B `.litertlm` from `litert-community` on Hugging Face (Apache-2.0, not gated), OkHttp, kotlinx.serialization, JUnit 4, MockWebServer, Paparazzi 2.0.0-alpha04, Node `node:test` for one server change.

**Spec:** `docs/superpowers/specs/2026-10-25-on-device-ai-design.md` §7 (brain), §9 (failure rows), §10 (tests). Builds on plan (d) (`/api/facts`, `/api/propose`, `/api/shelf/readings`).

## Global Constraints

- Work on branch `feat/on-device-ai`. Gradle runs from `android/` with JBR 21 (`~/.jdks/jbr-21.0.11`); the server from the repo root.
- **Toolchain (checked 2026-10-25):**
  - Every LiteRT-LM release that supports Gemma 4 (0.10.2 onward) is compiled with Kotlin metadata 2.3+, which Kotlin 2.1.21 cannot read.
  - So the project moves to **Kotlin 2.3.0** and **Paparazzi 2.0.0-alpha04** (built with Kotlin 2.3.0 and layoutlib-api 31.13.2, which matches AGP 8.13).
  - AGP 8.13.1 and Gradle 8.14.3 stay.
- **LiteRT-LM is pinned to 0.16.1** (2026-08-18). It depends on kotlin-reflect 2.2.21 and coroutines 1.9.0, the same as ours. 0.17+ pulls coroutines 1.11 and Kotlin 2.4 metadata.
- **Model files, pinned by repo revision and SHA-256:**
  - E4B: `litert-community/gemma-4-E4B-it-litert-lm` @ `e6a3892a8c22cf87ff99583996149cf3cb32452b`, file `gemma-4-E4B-it.litertlm`, 3,659,530,240 bytes, sha256 `0b2a8980ce155fd97673d8e820b4d29d9c7d99b8fa6806f425d969b145bd52e0`.
  - E2B: `litert-community/gemma-4-E2B-it-litert-lm` @ `1caa527c1e88b55f046fcd8d2b4265606680663d`, file `gemma-4-E2B-it.litertlm`, 2,588,147,712 bytes, sha256 `181938105e0eefd105961417e8da75903eacda102c4fce9ce90f50b97139a63c`.
  - Both files were uploaded on 2026-05-04, before the runtime, and both URLs answer 200 with `accept-ranges: bytes`.
- **Model choice by RAM:** E4B when `totalMem ≥ 6,000,000,000` bytes, E2B when `≥ 3,500,000,000`, otherwise none (templates only). Phones sold as 8 GB report about 7.2–7.6 GB, which is why the threshold is 6e9 and not 7 GiB.
- **Time limits:** reword 6 s, answer 12 s, shelf 20 s. A timeout, an exception or a failed guard gives `null` and the template path.
- **Guards:**
  - A reworded line keeps every number and the final question mark, and its Roman line has no Devanagari.
  - An answer may only use numbers present in the facts, and only a `khataId` present in the facts.
  - Shelf readings use only known SKUs and the levels `empty | low | ok`.
- The model never acts: a suggested reminder becomes a server proposal that waits for "haan".
- The model file is downloaded on unmetered networks only; adb push is the stage path.
- Commit trailer on every commit: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```kotlin
package com.opuscube.munshi.brain

import com.opuscube.munshi.api.Facts
import com.opuscube.munshi.api.MunshiJson
import com.opuscube.munshi.api.Reading
import com.opuscube.munshi.api.Sku
import com.opuscube.munshi.voice.Line
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.contentOrNull
import kotlinx.serialization.json.jsonArray
import kotlinx.serialization.json.jsonObject
import kotlinx.serialization.json.jsonPrimitive
import kotlinx.serialization.json.longOrNull

// Small models drift: these checks decide whether a reply may be used at all. Anything doubtful is null.

private val DEVANAGARI = Regex("[\\u0900-\\u097F]")
private val LEVELS = setOf("empty", "low", "ok")

/** Every number in a line, commas dropped: "₹1,240" and "1240" are the same number. */
fun numbers(s: String): Set<String> =
    Regex("\\d[\\d,]*").findAll(s).map { it.value.replace(",", "") }.filter { it.isNotEmpty() }.toSet()

private fun firstJson(raw: String, open: Char, close: Char): String? {
    val a = raw.indexOf(open); val b = raw.lastIndexOf(close)
    return if (a >= 0 && b > a) raw.substring(a, b + 1) else null
}

/** Two lines back: Roman Hinglish, then Devanagari. Same numbers, same question; else null. */
fun parseReword(raw: String, template: Line): Line? {
    val lines = raw.lines().map { it.trim().removeSurrounding("\"") }.filter { it.isNotEmpty() }
    val roman = lines.getOrNull(0) ?: return null
    val need = numbers(template.text)
    if (DEVANAGARI.containsMatchIn(roman) || !numbers(roman).containsAll(need)) return null
    if (template.text.trimEnd().endsWith("?") && !roman.trimEnd().endsWith("?")) return null
    val dev = lines.getOrNull(1)?.takeIf { DEVANAGARI.containsMatchIn(it) && numbers(it).containsAll(need) }
    return Line(roman, dev ?: template.spoken)
}

/** {"say", "spoken", "propose": {"kind":"udhaar_reminder","khataId"} | null}, checked against the facts. */
fun parseAnswer(raw: String, facts: Facts): BrainReply? {
    val obj = firstJson(raw, '{', '}')?.let { runCatching { MunshiJson.parseToJsonElement(it).jsonObject }.getOrNull() } ?: return null
    val say = obj["say"]?.jsonPrimitive?.contentOrNull?.trim().orEmpty()
    if (say.isEmpty() || DEVANAGARI.containsMatchIn(say)) return null
    val known = numbers(MunshiJson.encodeToString(Facts.serializer(), facts))
    if (!known.containsAll(numbers(say))) return null                  // never a number the shop's data does not have
    val spoken = obj["spoken"]?.jsonPrimitive?.contentOrNull?.trim()
        ?.takeIf { DEVANAGARI.containsMatchIn(it) && known.containsAll(numbers(it)) }
    val propose = obj["propose"] as? JsonObject
    val khataId = propose?.get("khataId")?.jsonPrimitive?.longOrNull
    if (propose != null && (khataId == null || facts.khata.none { it.khataId == khataId })) return null
    return BrainReply(Line(say, spoken), khataId)
}

/** A JSON array of {"sku","level"}; unknown SKUs and levels dropped; nothing usable is null. */
fun parseShelf(raw: String, items: List<Sku>): List<Reading>? {
    val arr = firstJson(raw, '[', ']')?.let { runCatching { MunshiJson.parseToJsonElement(it).jsonArray }.getOrNull() } ?: return null
    val skus = items.map { it.sku }.toSet()
    return arr.mapNotNull { e ->
        val o = e as? JsonObject ?: return@mapNotNull null
        val sku = o["sku"]?.jsonPrimitive?.contentOrNull
        val level = o["level"]?.jsonPrimitive?.contentOrNull
        if (sku != null && level != null && sku in skus && level in LEVELS) Reading(sku, level) else null
    }.takeIf { it.isNotEmpty() }
}
```

```kotlin
package com.opuscube.munshi.brain

import com.opuscube.munshi.api.Facts
import com.opuscube.munshi.api.Reading
import com.opuscube.munshi.api.Sku
import com.opuscube.munshi.voice.Line
import kotlinx.coroutines.CancellationException
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.withTimeoutOrNull
import java.util.concurrent.ConcurrentHashMap

/** One-shot generation on the phone. No history: every call is a fresh conversation. */
interface Llm {
    suspend fun generate(system: String, user: String, image: ByteArray? = null): String
}

class LlmBrain(
    private val llm: Llm,
    override val state: StateFlow<BrainState>,
    private val rewordMs: Long = 6_000,
    private val answerMs: Long = 12_000,
    private val shelfMs: Long = 20_000,
) : Brain {
    private val worded = ConcurrentHashMap<String, Line>()   // template text → warmer wording
    private val ready get() = state.value == BrainState.Ready

    override fun cached(line: Line): Line? = worded[line.text]

    override suspend fun prewarm(lines: List<Line>) {
        for (l in lines) {
            if (!ready || worded.containsKey(l.text)) continue
            val raw = ask(rewordMs) { llm.generate(Prompts.REWORD, l.text) } ?: continue
            parseReword(raw, l)?.let { worded[l.text] = it }
        }
    }

    override suspend fun answer(question: String, facts: Facts): BrainReply? {
        if (!ready) return null
        val raw = ask(answerMs) { llm.generate(Prompts.answer(facts), question) } ?: return null
        return parseAnswer(raw, facts)
    }

    override suspend fun readShelf(jpeg: ByteArray, items: List<Sku>): List<Reading>? {
        if (!ready) return null
        val raw = ask(shelfMs) { llm.generate(Prompts.SHELF, Prompts.shelf(items), jpeg) } ?: return null
        return parseShelf(raw, items)
    }

    // A slow or failing model is a missing answer, never a crash: the templates take over.
    private suspend fun ask(ms: Long, block: suspend () -> String): String? = try {
        withTimeoutOrNull(ms) { block() }
    } catch (e: CancellationException) {
        throw e
    } catch (e: Exception) {
        null
    }
}
```

```kotlin
package com.opuscube.munshi.brain

import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.ensureActive
import kotlinx.coroutines.withContext
import okhttp3.OkHttpClient
import okhttp3.Request
import java.io.File
import java.io.FileOutputStream
import java.security.MessageDigest

fun sha256(f: File): String {
    val md = MessageDigest.getInstance("SHA-256")
    f.inputStream().use { s -> val buf = ByteArray(1 shl 16); while (true) { val n = s.read(buf); if (n < 0) break; md.update(buf, 0, n) } }
    return md.digest().joinToString("") { "%02x".format(it) }
}

// One pinned file, resumable: bytes land in <dest>.part (a Range request continues it), and only a file
// whose SHA-256 matches becomes <dest>.
class ModelDownloader(private val client: OkHttpClient) {
    suspend fun fetch(file: ModelFile, dest: File, onProgress: (Long, Long) -> Unit): Boolean = withContext(Dispatchers.IO) {
        val part = File(dest.path + ".part")
        val have = if (part.isFile) part.length() else 0L
        val req = Request.Builder().url(file.url).apply { if (have > 0) header("Range", "bytes=$have-") }.build()
        val ok = client.newCall(req).execute().use { res ->
            if (!res.isSuccessful) return@use false
            val append = res.code == 206
            var done = if (append) have else 0L
            val body = res.body ?: return@use false
            FileOutputStream(part, append).use { out ->
                body.byteStream().use { input ->
                    val buf = ByteArray(1 shl 16)
                    while (true) {
                        ensureActive()
                        val n = input.read(buf); if (n < 0) break
                        out.write(buf, 0, n); done += n; onProgress(done, file.bytes)
                    }
                }
            }
            true
        }
        if (!ok) return@withContext false
        if (sha256(part) != file.sha256) { part.delete(); return@withContext false }
        dest.delete()
        part.renameTo(dest)
    }
}
```

```kotlin
package com.opuscube.munshi.brain

import android.app.ActivityManager
import android.content.Context
import android.net.ConnectivityManager
import android.net.NetworkCapabilities
import android.os.SystemClock
import android.util.Log
import com.google.ai.edge.litertlm.Backend
import com.google.ai.edge.litertlm.Content
import com.google.ai.edge.litertlm.Contents
import com.google.ai.edge.litertlm.ConversationConfig
import com.google.ai.edge.litertlm.Engine
import com.google.ai.edge.litertlm.EngineConfig
import com.google.ai.edge.litertlm.ExperimentalApi
import com.google.ai.edge.litertlm.ExperimentalFlags
import com.google.ai.edge.litertlm.SamplerConfig
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.launch
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import kotlinx.coroutines.withContext
import okhttp3.OkHttpClient
import java.io.File

// The model on this phone: picks E4B or E2B by memory, takes a file pushed by adb or downloads it on
// Wi-Fi, loads it once (GPU, else CPU) and serves one generation at a time.
class ModelHost(private val context: Context, private val scope: CoroutineScope, private val http: OkHttpClient) {
    private val _state = MutableStateFlow<BrainState>(BrainState.Missing)
    val state: StateFlow<BrainState> = _state
    private val dir = File(context.filesDir, "models")
    private val lock = Mutex()
    @Volatile private var engine: Engine? = null
    private var backendName = "?"

    val llm: Llm = object : Llm {
        override suspend fun generate(system: String, user: String, image: ByteArray?): String = lock.withLock {
            withContext(Dispatchers.IO) {
                val t0 = SystemClock.elapsedRealtime()
                run(system, user, image).also {
                    Log.i(TAG, "${SystemClock.elapsedRealtime() - t0} ms · $backendName · ${if (image != null) "image + " else ""}${user.take(40)}")
                }
            }
        }
    }

    fun start() { scope.launch(Dispatchers.IO) { prepare() } }

    private suspend fun prepare() {
        val m = Models.forRam(totalRam()) ?: run { _state.value = BrainState.Unsupported; return }
        dir.mkdirs()
        val file = File(dir, m.name)
        if (!file.isFile) {
            if (!onUnmeteredNetwork()) { _state.value = BrainState.Missing; return }   // next start on Wi-Fi, or adb push
            if (dir.usableSpace < m.bytes + 500_000_000) { _state.value = BrainState.Failed("not enough space"); return }
            var shown = -1L
            val ok = ModelDownloader(http).fetch(m, file) { done, total ->
                if (done - shown >= 20_000_000 || done == total) { shown = done; _state.value = BrainState.Downloading(done, total) }
            }
            if (!ok) { _state.value = BrainState.Failed("download"); return }
        }
        _state.value = BrainState.Loading
        engine = load(file)
        _state.value = if (engine != null) BrainState.Ready else BrainState.Failed("load")
        Log.i(TAG, "model ${m.name} → ${_state.value} on $backendName")
    }

    @OptIn(ExperimentalApi::class)
    private fun load(file: File): Engine? {
        ExperimentalFlags.enableSpeculativeDecoding = true
        for ((name, backend) in listOf("gpu" to Backend.GPU(), "cpu" to Backend.CPU())) {
            val e = runCatching {
                Engine(EngineConfig(modelPath = file.path, backend = backend, visionBackend = backend, maxNumImages = 1, cacheDir = context.cacheDir.path))
                    .also { it.initialize() }
            }.onFailure { Log.w(TAG, "$name backend failed", it) }.getOrNull()
            if (e != null) { backendName = name; return e }
        }
        return null
    }

    // A fresh conversation per call: no history leaks between questions or customers.
    private fun run(system: String, user: String, image: ByteArray?): String {
        val e = engine ?: error("model not ready")
        val config = ConversationConfig(
            systemInstruction = Contents.of(system),
            samplerConfig = SamplerConfig(topK = 40, topP = 0.95, temperature = 0.3),
            maxOutputToken = 256,
        )
        return e.createConversation(config).use { c ->
            val input = if (image != null) Contents.of(Content.ImageBytes(image), Content.Text(user)) else Contents.of(user)
            c.sendMessage(input).contents.contents.filterIsInstance<Content.Text>().joinToString("") { it.text }
        }
    }

    private fun totalRam(): Long =
        ActivityManager.MemoryInfo().also { context.getSystemService(ActivityManager::class.java).getMemoryInfo(it) }.totalMem

    private fun onUnmeteredNetwork(): Boolean {
        val cm = context.getSystemService(ConnectivityManager::class.java)
        return cm.getNetworkCapabilities(cm.activeNetwork)?.hasCapability(NetworkCapabilities.NET_CAPABILITY_NOT_METERED) == true
    }

    private companion object { const val TAG = "MunshiBrain" }
}
```

```powershell
if (-not (Test-Path $file) -or (Get-FileHash $file -Algorithm SHA256).Hash.ToLower() -ne $want) {
  Write-Host "Downloading $name (resumable)"
  & curl.exe -L -C - --fail -o $file "https://huggingface.co/litert-community/$repo/resolve/$rev/$name"
  if ($LASTEXITCODE -ne 0) { throw "download failed ($LASTEXITCODE)" }
}
$got = (Get-FileHash $file -Algorithm SHA256).Hash.ToLower()
if ($got -ne $want) { throw "SHA-256 mismatch: $got" }
Write-Host "Pushing $name"
Adb push $file "/data/local/tmp/$name"
Adb shell "run-as $app mkdir -p files/models && cat /data/local/tmp/$name | run-as $app sh -c 'cat > files/models/$name.part && mv files/models/$name.part files/models/$name' && rm /data/local/tmp/$name"
Adb shell "run-as $app ls -l files/models"
```
